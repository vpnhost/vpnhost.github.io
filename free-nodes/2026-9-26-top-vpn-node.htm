动手之前，你需要准备什么？

在正式开始之前，请务必确认你手头有这三样东西：

  1. 一台VPS（虚拟专用服务器）：这是你代理服务的“家”。推荐选择海外机房，例如美国、日本、新加坡、韩国等地的VPS。系统建议选择Debian 10/11或Ubuntu 20.04/22.04 LTS，因为这两个系统的环境最干净，兼容性问题最少。CentOS 7虽然也可以用，但官方已停止维护，不建议新用户选择。配置方面，1核CPU、512MB内存就足够跑V2Ray了，如果是1GB内存体验会更丝滑。价格方面，年付十几到二十几美元的入门款就完全够用。

  2. 一个SSH终端工具：Windows用户推荐使用PuTTY或Windows Terminal（自带的ssh命令），macOS或Linux用户直接打开系统自带的“终端”即可。这个工具用来远程连接你的VPS。

  3. 一颗勇于折腾的心：虽然脚本是“一键”的，但过程中难免会遇到网络波动、安装超时等小插曲。请保持耐心，遇到问题不要慌，文末我会列出常见问题的解决方法。

保姆级操作步骤：跟着做就行

当你通过SSH成功登录到VPS后，屏幕上会显示一串类似 root@your-server:~# 的提示符。下面，我们开始正戏。

第一步：确认你的登录身份

如果你是以普通用户登录的，请先切换到root权限，或者使用带有sudo前缀的命令。为了省去后续权限麻烦，建议直接使用root用户操作。如果你用的是Ubuntu，登录后输入 sudo -i 并回车，就能切换成root。

第二步：下载并执行一键脚本

在命令行中，输入以下这行神秘代码，然后按回车：

bash bash <(curl -s -L https://raw.githubusercontent.com/233blog/v2ray/master/install.sh)

这里简单解释一下这行命令在做什么：curl 负责从GitHub上把脚本文件下载下来，bash 则立刻把下载的内容交给解释器执行。-s 表示静默模式（不显示进度条），-L 表示如果遇到重定向就自动跟随。这里有一个关键提醒：如果你在国内的VPS上执行此命令，可能会因为网络原因无法访问GitHub，导致下载失败。此时，你可以使用代理，或者将命令中的 raw.githubusercontent.com 替换为 raw.gitmirror.com（一个GitHub加速镜像），即：

bash bash <(curl -s -L https://raw.gitmirror.com/233blog/v2ray/master/install.sh)

执行后，脚本会自动检测系统环境，并开始下载V2Ray核心文件。这个过程快则几十秒，慢则几分钟，取决于你VPS的网络速度。

第三步：跟着向导做选择题

安装脚本跑起来后，你会看到一排蓝色的菜单，通常是让你选择传输协议。对于绝大多数新手，我强烈推荐选择 1 (VMess + TCP + TLS) 或者 2 (VMess + WebSocket + TLS)。如果你没有域名，暂时不想折腾TLS证书，那么选 4 (VMess + TCP) 也可以，但安全性不如TLS加密。

选择后，脚本会问你是否需要“设置端口”。如果你不懂，直接按回车使用随机端口即可。接着，它会问你是否需要“设置UUID”（用户ID）。同样，直接回车，脚本会生成一个唯一的随机ID。最后，脚本会显示所有配置信息，并要求你确认。输入 y 并回车。

第四步：见证奇迹的时刻

确认后，脚本会完成最后的配置写入并启动V2Ray服务。当屏幕上出现绿色的“安装成功”字样，并展示出你的端口号、UUID、传输协议以及客户端连接地址时，恭喜你，你的私人节点已经搭建完成！请务必截图或复制保存这些信息，稍后客户端配置会用到。

安装完成后的客户端配置

服务器端搞定后，你还需要在本地电脑或手机上装一个V2Ray客户端。

  • Windows：推荐使用 v2rayN。
  • macOS：推荐使用 V2RayU 或 Qv2ray。
  • Android：推荐使用 v2rayNG。
  • iOS：推荐使用 Shadowrocket（小火箭） 或 Quantumult X（后两者需付费）。

以Windows的v2rayN为例，打开软件后，点击服务器图标，选择“添加[VMess]服务器”。在弹出的窗口中，填入你刚才保存的服务器地址（VPS的IP）、端口、UUID（用户ID）。在“传输协议”一栏，选择你安装时选的类型（TCP或WebSocket）。如果选了WebSocket，还需要在“路径”中填入脚本生成的路径（通常是 / 后面跟一串随机字符）。设置好后，点击“确定”。最后，右键点击系统托盘中的v2rayN图标，选择“系统代理” -> “自动配置系统代理”。浏览器打开一个海外网站试试，如果能正常访问，说明你的节点已经成功工作了。

进阶优化：让节点跑得更稳更安全

基础的节点能用，但如果你想让它更持久、更稳定，还需要做一些小优化。

1. 开启BBR加速：BBR是Google开发的一种拥塞控制算法，能显著提升网络吞吐量，降低延迟。对于VPS来说，开启BBR几乎是必做的优化。你可以在SSH中输入以下命令：

bash bash <(curl -s -L https://github.com/teddysun/across/raw/master/bbr.sh)

按照提示重启后，再执行 lsmod | grep bbr，如果看到 tcp_bbr 模块，说明开启成功。

2. 配置防火墙：如果你VPS上启用了防火墙（如iptables或firewalld），请务必放行你刚才设置的V2Ray端口。否则，即使客户端配置正确，也无法连接。例如，如果端口是 12345，在iptables上执行：

bash iptables -I INPUT -p tcp --dport 12345 -j ACCEPT

3. 定期更新V2Ray内核：网络封锁技术日新月异，V2Ray也在不断更新以对抗封锁。233blog脚本提供了更新功能。你只需再次执行脚本，选择菜单中的“更新V2Ray”即可。建议每两三个月检查一次。

常见问题与排坑指南（亲身经历）

问题1：脚本下载失败，提示curl: (7) Failed to connect to raw.githubusercontent.com port 443。

这是最典型的问题，原因是你所在的VPS无法访问GitHub。解决办法就是上面提到的，使用镜像地址 raw.gitmirror.com 替换原地址，或者手动下载脚本文件上传到VPS再执行。

问题2：安装成功了，但手机/电脑客户端连不上。

首先，检查你的客户端填写的端口、UUID、协议是否和服务器端完全一致。尤其是UUID，不要复制漏了字符。其次，检查VPS防火墙是否放行端口。最后，用 systemctl status v2ray 查看V2Ray服务是否在运行中。如果显示 active (running)，则服务正常，问题出在客户端或防火墙。

问题3：连接显示“超时”或“握手失败”。

这通常意味着你的IP或端口被封了。如果你用的是国内VPS，基本不存在这个问题；如果是海外VPS，则可能是IP被GFW针对性封锁。解决办法是更换端口，或者更彻底地——换一台VPS。另外，如果你搭建了TLS，但证书过期或配置错误，也会导致握手失败。这时需要进入脚本菜单，重新申请或续期证书。

问题4：速度很慢，看视频卡顿。

先检查你的本地网络是否正常。如果本地没问题，那大概率是VPS的带宽或线路问题。便宜的VPS通常使用普通线路，晚高峰拥堵严重。如果想要流畅的4K体验，建议选择CN2 GIA或IPLC等优质线路的VPS，价格会高一些，但体验完全不同。此外，开启BBR能带来一定改善。
